# CME · 资本市场预期｜知识点图谱

一、学科复习建议

经济学这个学科该怎么复习？

 M 1侧重宏观分析，M 2侧重微观分析。

注重经典计算题的计算，这类题目较为固定简单，好拿分。

定性题目更为灵活，需要注重理解。

讲义包含了原版书重要结论，最好可以自己默写讲义结论。

需要练习的题目：原版书课后题、讲义上的例题、历年真题、MOCK题（过往不少题

目仍有借鉴性）。
