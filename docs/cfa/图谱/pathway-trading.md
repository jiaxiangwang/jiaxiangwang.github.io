# Trading · 交易执行（Pathway）｜知识点图谱

一、学科复习建议

Pathway -Trading这个学科该怎么复习？

三级Pathway -Trading讲述的是与交易相关的各方面内容，具体包含四部分：交易策

略以及策略选择、交易执行、交易成本计算、交易政策。其中只有交易成本计算是定量

考查，且考查形式固定，考题只是换数字而已，考查频率高，是一个性价比很高的知识

点，必须要拿分。其余三部分均以定性结论为主。

听课建议：从复习角度来看，争取听一遍视频后就能对关键知识点有一定的掌握。由于

考点相对集中，抓住重要知识点能够起到事半功倍的效果。

做题建议：原版书课后题、经典题、基础班讲义例题以及近两年M OCK题，尤其强调

经典题的重要性。需要强调一点：由于考纲的变化，本学科2020年之前的题目没有参

考性。

复习建议：建议大家可以自行梳理、总结章节知识框架，从而做到有效的输出和复习。

并且，可以总结自己的错题本，把做错的题目记录下来，反复练习，一定要在理解的基

础上进行练习。
