# Derivatives · 衍生品与外汇管理｜知识点图谱

一、学科复习建议

衍生与外汇管理这个学科该怎么复习？

 Intro：

M 1,M 2是关于衍生品的内容，整体难度不大，以定量考察为主，题型比较固定，
复习时重视提高做题速度和答题正确率。

- ✓ M 3是外汇管理部分的内容，整体难度较大，考察方式灵活，应重视知识点的理

解，在理解的基础上多做练习，尤其注意讲义例题的掌握。

复习建议：



- ✓ 重视听课：听课时不要只追求听课的速度，应做好笔记，对于比较难理解的内容，

要多次碾压式听课与总结；注意掌握课程中何老师讲的例题；

- ✓ 多做题：包括经典题，押题，课后题以及题库的题目。需要注意外汇管理部分的

课后题，题目质量很高，一定要保证会做；期权策略这部分的课后题，题目较简

单，不要掉以轻心；互换、远期和期货这一章的课后题也应要着重掌握。
