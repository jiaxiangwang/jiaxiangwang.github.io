# 另类投资 · Alternative

一、学科复习建议

另类这个学科该怎么复习？

主要介绍组合中加入另类资产后的情况。

注重经典计算题的计算，这类题目虽然有别于传统思路，但是较为固定简单，好拿分。

定性题目更为灵活，需要注重理解。

本学科主要是结论的内容，讲义已包含原版书重要结论，最好可以自己默写讲义结论。

需要练习的题目：原版书课后题、讲义上的例题、经典题，学有余力情况下练习一下官

网题（practice）。
