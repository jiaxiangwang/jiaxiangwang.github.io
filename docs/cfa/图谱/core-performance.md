# Performance · 绩效评估｜知识点图谱

一、学科复习建议

Performance Measurement这个学科该怎么复习？

三级Core-Performance Measurement包含两个相对独立的话题，共分为两章：

o LM1与业绩评价相关，具体包含三部分：Performance Attribution、Benchmark、

Performance Appraisal（七个指标的计算）。重难点集中在收益归因，考查频率

高，既有画矩形图计算，也有表格理解。总体来说，LM1既有定性考查，也牵涉

定量计算。

o LM2与基金经理选择相关，主要包含两部分：Quantitative Elements、Qualitative

Elements，同时还包含一个小话题：一二类错误。LM2主要以定性结论为主。

听课建议：从复习角度来看，争取听一遍视频后就能对关键知识点有一定的掌握。由于



考点相对集中，抓住重要知识点能够起到事半功倍的效果。

做题建议：原版书课后题、经典题、基础班讲义例题以及近两年M OCK题，尤其强调

经典题的重要性。需要强调一点：由于考纲的变化，本学科2020年之前的题目没有参

考性。

复习建议：建议大家可以自行梳理、总结每个章节的知识框架，从而做到有效的输出和

复习。并且，可以总结自己的错题本，把做错的题目记录下来，反复练习，一定要在理

解的基础上进行练习。
