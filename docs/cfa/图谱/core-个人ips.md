一、学科复习建议

个人IPS只有M4，整体以结论为主,税收部分需要掌握计算。

基础班讲义和框架图包含了原版书重要结论，最好可以自己默写框架图结论。

重点练习的题目：原版书课后题、讲义例题及经典题等。
