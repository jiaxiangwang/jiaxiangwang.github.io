# 全球业绩标准 · GIPS

一、学科复习建议

GIPS这个学科该怎么复习？

本学科主要讲解投资公司如何公平地展示自己的业绩。了解了这个前提后再去学习就会

轻松一些。

近些年考试占比提升。一般为一个case。

注重业绩相关的计算，这类题目较为灵活，数字繁多，容易出现错误，需要多加练习。

定性题目同样出题灵活，需要注重理解，以及注重题干中的细节信息。

讲义包含了原版书重要结论，今年学科放在Performance Measurement下，有可能

考主观题了，最好可以自己默写讲义的重要结论。

需要练习的题目：原版书课后题、讲义上的例题，学有余力情况下练习一下官网题

（practice）。
