# Fixed Income · 固定收益（Pathway）｜知识点图谱

一、学科复习建议

Fixed-Income这个学科该怎么复习？

 Pathway共有三个Learning Module，每章难度都较大。在复习备考时，应该分配

足够多的时间。

需要记忆背诵的内容很少，重点是需要理解知识点及背后的原理。考试题目比较灵

活，只有理解原理才能应对考题。

需要练习的题目（按重要性排序）：原版书课后题>经典题= 25年之后的Mock

题>押题>讲义例题>协会官网题库（可选择不做）。
