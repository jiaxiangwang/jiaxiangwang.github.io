# 机构 IPS · 机构投资者｜知识点图谱

一、学科复习建议

Institutional IPS这个学科该怎么复习？

本学科有两个Module，其中M5为机构IPS的正文内容，M7为机构IPS的Case

study，这两部分涉及到的知识点都相对比较简单。

学员应以最快的速度过完基础班课程，做好笔记，争取只过一遍基础班视频，为其

他权重更大的科目留出时间。

基础班讲义是完全遵照原版书编写的，内容涵盖全，逻辑性更好。学员只需把握好

基础班讲义即可，无需学习原版书。

后期复习以笔记和框架图为主，可以反复过框架图与笔记。

这门课的重点突出：投资模型，DB与Endowment (Foundation)以及银行Equity

duration（包含计算）与Volatility的影响分析是重点。

往年真题不适用，知识点的考法与方向已经发生了很大变动，学员不用参考往年真
