# 权益 · Equity（Pathway）

一、学科复习建议

权益这个学科该怎么复习？

难度：3个Learning Module s，LM 1中等难度，而LM 2和LM 3较难

重要性：依次递增，特别是最后两个，考察频率高

整体偏定性，内容抽象，因此复习建议是反复听视频，在理解的基础上记忆

计算少且容易，但是每个计算都是重要考点，建议多做题，以确保计算类题目不丢分

课下复习：多听视频、刷题库
