# 私人财富管理 · 个人IPS

## 基尼系数

1. 基尼系数（Ginicoefficient）：是一种更具广泛基础的不平等衡量指标，它关注财富范围的整体情况，证实了财富分配的不均衡性。
2. 基尼系数的取值范围是0到1，其中0代表完全平等（每个人都获得相等份额的财富），1代表完全不平等（一个人拥有所有财富）。
3. 它将洛伦兹曲线（Lorenz Curve ）（即各人口百分比所拥有财富的累计百分比）与完全平等线进行比较，在完全平等线上，财富在人口中均匀分配。即每一个人口百分比都拥有相等的财富百分比。

财富

1. 总财富（Aggregate wealth ）：指所拥有的所有资产的总价值，包括个人财产、金融资产、实物资产和权益。
2. 个人财产(Personal property）：通常包括汽车、衣物、家具和个人住宅等物品。一般来说，个人资产预计不会增值，而且对个人而言，其价值往往高于当前的公平市场价值。
3. 金融财富(Financialwealth ）：包括所有金融资产，如公开交易的股票、债券、共同基金以及另类资产（对冲基金、私募股权）。不包括对非公开交易企业的直接所有权。金融资产很容易识别，包括有形资产和无形资产。
4. 实际财富（Real Wealth ）：指的是诸如房地产和大宗商品之类的有形资产，不包括个人财产和金融资产。
5. 流动性财富（Liquid Wealth ）：易于转换为现金的资产，包括公开交易的股票、债券、现金、现金等价物和银行存款。
6. 可投资财富（Investablewealth）：随时可用于投资的资产，通常是金融资产的一个子集。

## 人生的财务阶段

1. 教育阶段（The Education Phase ）：发生在进入职场之前，此时个人通常在经济上依赖他人，且积蓄甚少。
2. 早期职业生涯阶段（The EarlyCareer Phase ）：始于进入职场时。个人可能会结婚、组建家庭、买房，并开始为子女的教育储蓄。
3. 职业发展阶段（The Career Development Phase ）：发生在35岁至50岁之间，其特点是技能提升、职业发展和收入增加。大量的家庭和住房支出可能会限制储蓄，而人力资本是总财富的一大部分。
4. 财富积累高峰期（The Peak Accumulation Phase ）：大约在50 - 60岁左右开始，此时个人收入达到最高水平，并专注于财富积累。在此阶段，退休规划和最小化税务成为主要目标。
5. 退休前阶段（The Pre-Retirement Phase ）：发生在退休前几年。代表职业生涯的最高收入和财富积累的顶峰。
6. 早期退休阶段（The Early Retirement Phase ）：这是退休后最活跃的时期，认知或行动能力受限较少。继续承担适当的投资风险对于维持资产增长很重要。
7. 晚期退休阶段（The Late Retirement Phase ）：由于长寿风险而充满不确定性。

## IPS的组成

1. 背景（Background ）：包括客户的个人信息、财务信息以及税收信息。
2. 投资目标（ Investment Objectives ）：客户长期和短期的目标，基金经理在处理多个目标时，应优先考虑首要目标。
3. 投资参数（Investment parameters ）：包括风险承受能力、投资期限、资产类别偏好、其他投资偏好、流动性偏好、限制条件和投资组合资产配置。
4. 组合管理（Portfoliomanagement ）：包括权限类型、再平衡、战术调整以及实施。
5. 职责和责任（Duties and responsibilities）：包括财富经理职责和投资政策声明审查。
6. 附录（Appendix ）:投资政策声明的附录通常包含一些细节，这些细节的变动频率通常比IPS主体部分更高。
