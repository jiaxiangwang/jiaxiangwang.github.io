# 机构 IPS · 机构投资者

机构投资者共同特征

1.规模（Scale）：小机构受限于投资门槛和专业能力，依赖外部管理；大机构面临规模不经济（如私募股权容量限制），需平衡流动性与收益。投资期限（Long -Term Horizon）：养老金、主权基金等长期投资者可配置私募股权、房地产等非流动性资 2. 产；银行、财险公司因短期负债需求侧重流动性资产。治理框架（Governance Framework）：三层架构（董事会、投资委员会、执行团队），需解决委托代理 3. 问题（如绩效薪酬设计）。监管与税收（Regulatory & Tax）：不同国家对养老金、保险公司的资本要求、税收优惠差异显著（如美国 4. 401 (k)税收递延）。

四类资产配置模型

1.挪威模式（Norway Model）：以60/40股债为主，被动管理，低成本但增值潜力有限。捐赠基金模式（Endowment Model）：高比例另类投资，主动管理，适合长投资期和高风险容忍度。 2. 加拿大模式（Canada Model）：内部管理为主，引入参考投资组合（Reference Portfolio）和总组合方法 3. （TotalPortfolioApproach）。 负债驱动投资（Liability-Driven Investing,LDI）：对冲利率风险（如久期匹配），分为对冲组合 4. （Hedging Portfolio）和收益生成组合（Return-Generating Portfolio）。

养老金计划

1.设定受益计划（Defined BenefitPlan)：负债为未来支付的现值，受服务年限、薪资增长、死亡率等因素影响。 ⚫ 资金比率（Funded Ratio）=资产公允价值/负债现值，衡量偿付能力。 ⚫ 久期匹配（Duration Matching）和现金流匹配（Cash Flow Matching）用于管理利率风险。 ⚫ 固定缴款计划（Defined Contribution Plan):参与者自行承担投资风险，常见生命周期策略（Life-Cycle 2. Options）和目标日期基金（Target Date Funds）。资金比率计算：Funded ratio=计划资产的公允价值（Fairvalue of plan assets）/设定受益义务的现值 3. （PV ofDefined benefitobligations）

主权财富基金（SWF）

1.预算稳定基金（Budget StabilizationFunds）：对冲商品价格波动，投资高流动性债券，投资目标是资本保值，回报超过通胀。储蓄基金（Savings Funds）：跨代财富转移，配置高风险资产（如私募股权），投资目标是维持购买力， 2. 实现长期增值。储备基金（Reserve Funds）：提升外汇储备收益，降低负利差成本。 3. 4.养老储备基金（Pension Reserve Funds）：预筹养老金负债，长期投资股票和另类资产。

银行与保险公司
