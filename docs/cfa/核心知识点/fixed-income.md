# 固定收益 · Fixed Income

债券投资在组合内的作用

1.风险分散化（diversificationeffect）债券与股票、另类投资等其他资产的相关系数均小于1，将债券加入其他资产组合中将会分散化风险。 ⚫ 债券内部，投资级别的债券，投机级别的债券，公司债，国债等也具有较低的相关系数，不同类别的 ⚫ 债券组合可以降低风险，提供分散化。组合风险的大小除了取决于资产间的相关系数外，还取决资产自身的风险大小。作为大类资产，债券 ⚫ 自身的风险相对较小。资产间的相关系数会随时间，市场状态而改变。在市场危机时，各类资产的相关系数会大幅上升，出 ⚫ 现同跌的情况。

债券投资在组合内的作用

2.经常化的现金流（Regular cash flow）债券的现金流确定性高。当有负债需要管理时，可以用债券管理负债的现金流流出（cash outflow）。 ⚫ 对冲通货膨胀（inflationhedging potential） 3. 浮动利率债券的利息（coupon）会随着市场参考利率MRR的变动而变动。而市场参考利率会根据通货 ⚫ 膨胀率进行调整。所以，浮动利率债券产生的利息现金流会根据通胀调整，从而具备抵御通胀风险的能力。但浮动利率债券的本金不会对通胀调整，所以本金依然面临通胀风险。与通胀挂钩的债券（inflation-linked bonds）：债券的面值会随着通货膨胀的调整而调整，即债券的 ⚫ 本期面值=上一期旧面值×(1+本期通胀率)。而债券的每期利息coupon基于每期的新面值计算，这导致该类债券的面值与利息都会根据通货膨胀率的调整而调整，具备较好的抵御通胀能力。

债券投资策略的分类

1.债券的投资策略分为总收益策略（Total return mandate）以及以负债为目标的投资策略（Liability-based mandate） 总收益策略：投资的目标是追求收益最大化。下分三个策略，完全模拟债券指数的策略（pure ⚫ indexing）——试图获得与指数一样的收益和风险，即，投资组合完美复刻指数。加强型指数策略（enhanced indexing）——在整体匹配指数指标的同时，又试图一定程度偏离指数，获得一定的超额收益。完全主动的投资策略（active management）——该策略完全偏离指数，但会利用指数的收益作为评价基准。以负债为目标的投资策略：目标是用资产的收益、现金流完全匹配负债的现金流。分为以下几个具体 ⚫ 策略：现金流匹配策略（cash flow matching）,利率免疫策略（duration matching）,衍生品策略(derivativesoverlay),或有免疫策略(contingentimmunization)。

债券市场的流动性

1.和股票相比，债券市场的流动性相对更差。流动性差的债券会额外给投资者一个流动性补偿（liquiditypremium）。国债的流动性通常要强于公司债。因为国债的发行量更大，被市场广泛认可，且国债的违约风险极低（认为无违约风险）。低质量的债券流动性更低。经常在债券市场发行债券的企业，其债券流动性会更好，因为市场曝光度高。发 2. 行规模小的债券流动性要比规模大的债券低。长期债券的流动性通常要低于短期债券的流动性。3.流动性差的债券具有较高的买卖价差（bid-ask spread），这是因为做市商（dealer）为这类债券做市时，会承担较高的风险，他们会要求一个更高的收益补偿（买卖价差）。买卖价差（bid-ask spread）还可以反映债券的复杂程度与市场对该债券信用风险的评估。越是复杂的债券， 4. 如含权债券，其分析就越困难，市场参与者就越少，导致其买卖价差就越大。直接投资债券会承担债券流动性差的风险，可以使用其他间接的方法获得债券头寸，包括：公募基金 5. （mutual fund），ETF，衍生品头寸（如totalreturnswap）。

以负债为目标的投资策略

1.兼顾资产与负债的投资策略称为asset-liabilitymanagement（ALM），在投资时会兼顾资产与负债的指标，如duration和convexity。ALM是一级标题，下面细分两个二级标题，分别是Liability-driven investing（LDI）与Asset-driven 2. liability（ADL）。其中LDI是先有负债的信息，再去找合适的资产匹配负债，即负债发起资产投资。而ADL是先有资产信息，再去找合适的负债，这是资产发起负债。3.按照现金流的金额以及发生日是否明确，分为4类现金流模式。Type 1是现金流的发生金额明确且发生时间明确，如固定利率债券。Type 2是现金流金额明确，但发生时间不明确。如含权债券可能会被提前行权，导致现金流时间不确定。Type 3是现金流的金额不明确，但发生时间明确，如浮动利率债券，每期coupon的发生日确定，但是金额要取决于市场参考利率，而市场参考利率不能提前明确。Type 4是现金流的发生金额和时间都不能提前明确，如DB养老金。

以负债为目标的投资策略

4.最难管理的负债类型是Type 4现金流。Type 1现金流可以使用modified duration衡量利率风险，其他类型的现金流只能使用effectiveduration。现金流匹配策略（cash flow matching）：利用债券产生的本金和coupon现金流，匹配负债的现金流流出。 5. 在匹配时，是对负债的现金流流出进行逐笔分析，找到其金额和发生日，每一笔负债现金流cash outflow都是由一个债券的本金和多个债券的coupon共同偿还。现金流匹配策略是非常精细化的管理，是构建了一个负债的镜像资产来匹配。做到了资产与负债每笔现金流发生日、金额严丝合缝的一致。在一些会计准则下，被cash flow matching匹配的资产与负债可以被挪出资产负债表（accounting 6. defeasement），这样可以降低报表的负债率。
