# 全球业绩标准 · GIPS

## Fundamental of Compliance

1. Firm定义：公司必须被定义为投资公司、子公司或作为独立的商业实体向公众开放的部门。
2. Discretion定义：如果公司能够实现预期的投资策略，那么投资组合就是自由裁量的。
3. 遵守GIPS的基本原则：①GIPS标准是自愿遵守的；②GIPS标准必须在全公司范围内应用； ③公司必须遵守GIPS标准的所有适用要求。
4. 披露业绩时：公司不得将实际业绩与历史理论业绩联系起来。公司必须提供时间加权收益，除非满足某些条件，在这种情况下，公司可以提供货币加权收益。
5. Verification并不保证任何特定组合基金或集合基金列报的准确性。一份Verification报告只针对整个公司出具，不能对单个组合基金或集合基金进行核查。

## Input Data

1. 公司总资产：必须是公司管理的所有可自由支配和非可自由支配资产的公允价值总和。这包括付费和非付费的投资组合。
2. Input Data：投资组合必须按照公允价值的定义进行估值。

## Composite and Pooled Fund Maintenance

1. 自由裁量权：客户施加的约束是否可能对他/她执行投资策略的能力产生重大影响。
2. 所有实际的、付费的、可自由支配的segregated accounts必须至少包含在一个composite中。非可自由支配的投资组合不得包括在composite中。
3. 所有实际的、收费的、可自由支配的pooled fund必须包括在至少一个符合组合定义的组合中。公司不需要创建只包含一个或多个pooled fund的composite ，除非公司将该策略作为segregated accounts提供。
4. 不收费的可自由支配的portfolio可包括在composite中。
5. Composite必须根据投资要求、目标或策略来定义。
6. 对composite定义的任何更改都不能追溯地应用。

## 陈述和报告要求

1. 至少五年的业绩（若投资组合成立未满五年，则为自组合成立日起至报告期末的业绩），且需符合GIPS标准的要求。在公司提交至少五年的符合GIPS标准的业绩后，每年必须再提交一年的业绩，直至累计达到至少十年的符合GIPS标准的业绩。
2. 若初始期间不足一年，则为自组合成立日至初始年度期末的回报率。
3. 若组合终止，则为自上一年度期末至组合终止日的回报率。
4. 要披露组合中的投资组合数量（若≤5个，则无需列报）。
5. 要披露the composite and the benchmark的三年年化后的标准差
