# CME · 资本市场预期

制定资本市场预期的框架

以下是一套严谨制定的资本市场预期的标准流程框架。1.明确所需的预期内容，包括这些预期所适用的时间范围。研究历史记录。除了原始的历史事实之外，分析师应努力识别并理解那些影响资产类别回报的因素。 2. 明确要使用的方法/模型以及这些方法/模型对信息的要求。 3. 确定满足信息需求的最佳信息来源。找出那些能够提供最准确、最及时且符合自身需求信息的来源。 4. 运用选定的数据和方法，凭借经验和判断力来解读当前的投资环境。 5. 6.给出所需的预期内容，并记录相关结论，同时应附上这些结论背后的推理和假设。监控实际结果，并将其与预期进行比较，通过反馈来完善预期设定过程。 7.

对相关性的误解

在未对潜在的关联进行调查的情况下，不应将相关性关系用于预测模型。 1. 2.当发现变量A与变量B显著相关时，至少有四种可能的解释：（1）A能预测B；（2）B能预测A；（3）第三个变量C能同时预测A和B；（4）这种关系是虚假的。3.尽管表面上显著的相关性可能是虚假的，但缺乏强相关性也可能会产生误导。测得的相关性可忽略不计，可能反映出存在一种很强但却是非线性的关系。

模型不确定性

模型不确定性指的是所选择的模型在结构或概念上是否正确。模型不确定性可能是最为严重的问题，因为错 1. 误的模型可能会使分析师得出根本性错误的结论。参数不确定性的产生是由于量化模型的参数估计不可避免地存在误差。通过充分关注估计误差，可以减轻参 2. 数不确定性的影响。输入不确定性涉及输入数据是否正确。输入不确定性主要源于需要用代理变量来表示不可观测的变量，例如 3. 资本资产定价模型(CAPM)中的“市场投资组合”。4.上述任何一种不确定性或所有不确定性共同作用，都可能导致预测错误，使粗心的分析师高估其预测的准确性和可靠性。

新兴市场股票投资风险

新兴市场债券风险背后的大多数问题，同样也会给新兴市场股票带来风险：经济体更为脆弱、政治和政策框 1. 架更不稳定，以及法律保护更薄弱。然而，由于股票和债券的性质不同，这些风险会以不同的形式呈现。新兴市场是一个非常多样化的群体。通常与新兴市场相关的政治、法律和经济问题，实际上可能并不适用于 2. 所分析的特定市场或国家。国家风险因素的影响往往仍比（全球）行业因素的影响更为重要。这在新兴市场尤其如此。 3.

资本化率

资本化率反映长期折现率，我们应当预期其随长期利率总体水平而升降，这往往使其具有顺周期性。 1. 2.然而，资本化率也对信用利差和信贷可得性敏感。佩顿（2009）发现，资本化率与10年期国债收益率之间的利差，与3至5年期B级公司债的期权调整利 ⚫ 差呈正相关，与家庭和非金融部门债务占GDP的比率呈负相关。信用利差的逆周期特性会缓和资本化率的周期性波动。 ⚫ 由于房地产交易通常涉及大量杠杆，债务融资可得性的提高可能会降低预期房地产回报中所需的流动性 ⚫ 溢价部分。空置率上升会推高资本化率。 3. 对于风险更高的物业类型、质量较低的物业以及吸引力较差的地段，资本化率呈现出明显更高的规律。 4.
