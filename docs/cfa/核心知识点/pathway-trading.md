# 交易执行 · Trading（Pathway）

## 交易成本的来源

1. 市场冲击成本（Market Impact ）：由于交易带来的价格影响，通常大单或者交易较快的订单容易有较大的市场冲击成本。
2. Alpha衰减（Alpha Decay ）：表示α的衰减速度，如果衰减速度很快，为了抓住转瞬即逝的α，一定会快速交易。相反，如果衰减速度慢，那么可以选择慢慢交易。
3. 交易风险（Execution Risk）：可以直接等价于波动率，影响execution risk的是交易速度。交易得越慢，execution risk越大，不确定性越大；交易越快，execution risk越小，不确定性越小。

## 交易相关的名词

1. 交易紧迫性（Trade Urgency ）指在交易时间范围内，订单执行的快慢程度。交易紧迫性高，意味着在较短的执行期限内完成交易；交易紧迫性低，表示在较长的执行期限内完成交易。
2. 交易者两难（Trader’s Dilemma ）：交易速度过快，会对市场产生较大影响（market impact ），可能推动价格朝着不利于自己的方向变动，增加交易成本；而交易速度过慢，则会面临较高的执行风险（execution risk），比如因市场价格波动，无法按预期价格成交，甚至可能无法成交。
3. 交易策略选择目标：依据当前市场状况以及订单的独特属性，权衡价格和时间因素，找到最佳的价格-时间权衡点（the best price-time trade -off），实现交易效益的最大化。
4. 风险承受能力（RiskTolerance）：指投资者在投资过程中能够承受的风险程度。

## Reference Prices

1. 交易前基准（Pre-trade benchmarks ）：参考价格在交易开始前已知。
2. 日内基准（Intradaybenchmarks ）：参考价格根据交易期间出现的市场价格计算得出。
3. 交易后基准（Post-trade benchmarks ）：参考价格在交易完成后确定。
4. 价格目标基准（Price target benchmarks ）：参考价格被设定为需达到或超越（以实现更有利交易）的价格。

## Pre-Trade Benchmarks

1. 决策价格（Decision Price）：代表投资组合经理做出买卖证券决策时的证券价格。
2. 前收盘价（Previous Close）：指证券在前一交易日的收盘价。常被量化投资组合经理用作决策价格的替代指标。
3. 开盘价（Opening Price）：指证券当日的开盘价格。多由在市场开盘时就开始交易且希望最小化交易成本的投资组合经理指定。若交易在开盘集合竞价时执行，用开盘价作为参考基准不合适，因为交易本身会影响该参考基准。
4. 到达价格（ArrivalPrice）：指订单进入市场执行时的证券价格。当组合经理希望在接近当前市场价格完成交易（交易紧迫性较高）时使用。

## Intraday Benchmarks

1. 成交量加权平均价格（VWAP ）：是当日或交易期间内所有已执行交易的成交量加权平均价格。日内进行投资组合再平衡且同时有买卖订单的投资组合经理，可能会选择VWAP作为价格基准。与仅包含全部买入或全部卖出的交易清单相比，包含买卖的双边交易清单可降低市场风险暴露。
2. 时间加权平均价格（TWAP ）：指当日或交易期间内所有已执行交易的等权重平均价格。TWAP价格不考虑交易成交量，仅仅是特定时间段内已执行交易的平均价格。投资组合经理选择TWAP ，是为了排除潜在的异常交易。如果市场参与者无法充分参与这些交易，那么TWAP可能是更合适的选择。

## Scheduled algorithms

1. 成交量占比算法（POV ，percentage of volume algorithms /participationalgorithms）：指其成交量为市场成交量的占比，但是未考虑到成交价，也没有考虑到在交易期内是否能买全。POV只和volume有关，和时间没有关系，交易没有时限要求。当市场交易量增加时，这类算法会交易更多的股票；当交易量减少时，就会交易更少的股票。
2. 成交量加权平均价格算法（VWAP ，Volume -Weighted Average Price）：遵循指定的时间计划，在规定的时间内完成一定交易。根据历史日内成交量分布，将订单拆分成小单发送到市场。
3. 时间加权平均价格算法（TWAP ，Time -Weighted Average Price）：遵循指定的时间计划，在规定的时间内完成一定交易。按照等权重时间计划，将订单拆分成小单发送到市场。

## Execution Algorithm

1. 流动性探寻（LiquiditySeeking ）：通过在多个交易场所利用市场流动性获利。当出现有利价格的流动性时，加快交易速度。
2. 到达价格算法（Arrivalpricealgorithms）：旨在按订单接收时接近当前市场价格进行交易。到达价格算法在交易开始时会更积极地交易，以便在接近到达价格的水平上交易更多的股票。
3. 暗池聚合算法（Dark aggregator algorithms）：在不透明或透明度较低的交易场所执行交易，如暗池。
4. 智能订单算法（Smart Order Routers，SOR ）：指能依据实时市场状况，自动寻找最优交易路径的系统或算法。它会分析各交易场所（如不同证券交易所、电子交易平台）的流动性、价格等因素，将订单发送至最可能以理想价格高效执行的地方，帮投资者优化交易执行效果。

## Implementation Shortfall

1. 执行成本（Execution cost）：是因投资组合经理的买卖压力及相应市场风险而产生的成本。
2. 机会成本（Opportunity cost）：是由于价格不利变动或流动性不足，导致无法执行订单中所有股票而产生的成本。
3. 固定费用（Fixed fees）：包括所有显性费用，如佣金、交易所费用和税费。
