2. 跨式套利是针对标的资产波动率进行方向性操作的一个例子，表达了波动率将在当前水平上上升或下降的观点。

## 交叉货币基点互换

1. 本金需要进行交换。
2. 浮动换浮动：基点在互换的非美元一方报价。“支付”基点意味着借入另一种货币并贷出美元；“收取”基点意味着贷出另一种货币并借入美元。
3. 当对美元需求强劲时：使用交叉货币互换贷出等额美元并买入外币，能够增加收益。
4. 交叉货币基点利差会随时间变化，受信用、流动性因素以及交叉货币融资的供求关系驱动。
