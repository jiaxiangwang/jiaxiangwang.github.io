# 绩效评估 · Performance

Performance Evaluation

1.绩效衡量（Performance measurement）：这是绩效评估的基础步骤，主要通过特定的量化方法和指标，精确计算投资组合在一定时期内的业绩表现。例如，计算投资组合的收益率、波动率等，以此直观展现投资组合的盈利或亏损情况以及波动程度，为后续分析提供数据基础。绩效归因（Performance attribution）：在明确投资组合绩效表现后，进一步探究绩效达成的内在原因。 2. 这一步骤需要分析投资组合在各类资产配置、行业选择、个股选择等方面的决策，解释收益是如何通过这些具体决策实现的，或者风险是如何因这些因素而产生的。绩效评价（Performance appraisal）：基于前面的绩效衡量和归因分析，对投资组合的绩效质量进行综合 3. 性评判。通过深入分析投资组合在不同市场环境下的表现，判断投资组合的良好业绩是源于管理者卓越的投资技能，比如精准的资产配置能力、独到的选股眼光，还是仅仅得益于市场的偶然因素或运气成分，从而更准确地评估投资管理者的真实能力。

Performance Attribution

1.收益归因（Return attribution）：专注于探究主动投资决策对投资收益产生的影响。主动投资决策涵盖资产配置调整、个股选择等方面。风险归因（Riskattribution）：关注主动投资决策所引发的风险后果。 2. 微观归因（Micro attribution）：主要目的是深入理解投资经理收益的驱动因素。投资经理在日常投资操作 3. 中会做出众多决策，微观归因要剖析这些决策如何影响收益，同时，还要判断这些驱动收益的因素是否与投资经理所宣称的既定投资流程相契合。宏观归因（Macro attribution）：评估资产所有者（或基金发起人）的决策。衡量发起人偏离战略资产配 4. 置选择的影响，也衡量经理选择和时机决策的影响。

Performance Appraisal

1.夏普比率（Sharpe ratio）：衡量承担波动性（标准差）所获得的额外收益（超额收益）。特雷诺指数（Treynor Measure）：衡量分散良好的投资组合每单位系统性风险的超额收益。 2. 信息比率（Information Ratio）：衡量投资组合相对于基准的风险调整后绩效。 3. 评估比率（The AppraisalRatio）：即特雷诺-布莱克比率（Treynor–Black appraisalratio）。 4. 索蒂诺比率（Sortino Ratio）：是夏普比率的修正版。 5. 6.上行捕获率（UC）：衡量基准收益率为正时的收益获取情况；下行捕获率（DC），衡量基准收益率为负时的收益获取情况；捕获比率（CR）是上行捕获率除以下行捕获率。回撤（Drawdown）：衡量连续期间内从峰值到谷底的累计损失。回撤持续期，从回撤开始到累计回撤恢 7. 复至零的总时间。

StyleAnalysis

1.基于收益的风格分析（Returns - based styleanalysis）：一种自上而下的方法，通过给定时期内实际投资组合的收益序列，估计投资组合对代表一系列不同因素的证券市场指数的敏感度。基于持仓的风格分析（Holdings - based styleanalysis）：一种自下而上的方法，根据某一时刻投资组合 2. 中持有的实际证券来估计风险敞口。
