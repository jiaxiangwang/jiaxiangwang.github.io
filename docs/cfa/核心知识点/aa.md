# 资产配置 · AA

资产配置的三大核心框架

1.纯资产法(Asset-only approach)：仅考虑资产端，通过Mean -Variance Optimization (MVO)构建有效前沿，以Sharpe ratio为核心指标，但忽略负债和目标，适用于主权基金等。负债关联法(Liability-relativeapproach)：明确匹配负债，如养老金通过duration matching对冲利率风险， 2. 适用于保险、Defined Benefit(DB) plans。目标导向法(Goals-based approach)：将组合拆分为子组合匹配多目标（如教育、退休），结合mental 3. accounting和概率约束，适用于个人投资者。

投资治理的核心要素

1.治理架构(Governance structure)：三层架构（投资委员会、内部团队、第三方），明确职责分工（如委员会审批StrategicAsset Allocation(SAA)，团队执行）。投资政策说明(Investment PolicyStatement (IPS))：涵盖目标、约束、职责、再平衡规则等，是资产配置 2. 的基础文件。治理审计(Governance audit)：独立第三方评估政策有效性，避免key person risk和decision-reversalrisk。 3.

经济资产负债表与资产配置

1.扩展资产与负债(Extended assets and liabilities)：个人的human capital（类债券）、机构的未来收益权（如矿产资源）需纳入配置考量。生命周期分配逻辑(Life-cycle allocationlogic)：年轻投资者人力资本占比高（类债券），金融资产可更激 2. 进；退休后金融资产需保守，匹配consumption liability。

战略资产配置（SAA）流程

1.步骤(Steps)：量化目标与风险容忍度→设定资产类别→Capital Market Expectations (CME)→模拟测试（如Monte Carlo simulation）→确定目标权重。主要工具(Core tools)：Mean -Variance Optimization (MVO)（输入回报、波动、相关性）、Reverse 2. Optimization（从市场权重推导隐含回报）、Black-Litterman model（结合主观观点调整预期）。普遍缺点(Common pitfalls)：过度依赖历史数据，忽视non -normal distribution风险（如肥尾效应）。 3.

战术资产配置与再平衡

1.战术资产配置(Tacticalasset allocation, TAA)：短期偏离SAA捕捉市场机会，基于经济周期、momentum等信号，需控制trackingerror与交易成本。再平衡策略(Rebalancing strategies)： 2. 日历再平衡(Calendar rebalancing)：定期调整（如季度），简单但可能错过市场机会； ⚫ 百分比再平衡(Percentage-range rebalancing)：设定阈值（如±5%），成本与风险控制更优，需考 ⚫ 虑交易成本、税收和资产liquidity。税务影响(Taximplications)：Taxable投资者需扩大再平衡区间，减少capitalgains tax影响。 3.

风险预算与因子配置

1.风险预算(Risk budgeting)：将总风险分配至各资产类，目标是Marginal Contribution to Total Risk(MCTR)与超额回报比率一致，实现有效风险分散。因子投资(Factor-based investing)：以风险因子（如价值、动量、通胀）为单位构建组合，替代传统资产 2. 类别，更精准控制systematic risk（如用利率因子对冲负债久期）。应用挑战(Applicationchallenge)：因子不可直接投资，需通过资产组合（如多空策略）实现因子风险敞口。 3.

真实约束下的资产配置

1.监管和ESG限制(Regulatory and ESG constraints)：如保险公司受偿付能力监管，需匹配资产负债久期；ESG约束可能排除部分资产类别。规模限制(Scale constraints)：小投资者受限于非流动性资产（如privateequity），需通过fund-of-funds 2. 实现分散；大机构需注意策略规模上限（如对冲基金容量）。流动性和税收(Liquidityand taxes)： 3. 流动性需求高的组合（如应急基金）需高配cash equivalents。 ⚫ Taxable账户优先配置税收效率高的资产（如股票而非债券），免税账户放高税负资产（如高息债券 ⚫ high-yieldbonds）。

行为偏差对配置的影响

1.损失厌恶(Loss aversion)：过度规避风险，导致组合过于保守，可通过目标优先级分配缓解（如高优先级目标用低风险资产）。心理账户(Mental accounting)：将资产按目标拆分（如退休、教育），但需确保整体组合有效。 2. 近期偏差(Recency bias)：追逐近期表现好的资产，需通过长期数据回测和纪律性再平衡克服。 3.
