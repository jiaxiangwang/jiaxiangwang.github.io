# 权益 · Equity

## 股票在投资组合中的作用

1. 资本增值：从历史上看，主要由资本增值驱动的股票长期回报率，在主要资产类别中一直名列前茅。在经济强劲增长时期，股票往往比其他资产类别表现更优；而在经济疲软时期，其表现往往逊于其他资产类别。
2. 股息收入：股息收入是股票投资组合最常见的收入来源。当公司没有合适的项目，或者项目回报率不高于投资者要求的回报率时，公司会选择派发股息。
3. 与其他资产类别分散风险：和债券、现金等资产相关性低，可降低投资组合整体风险波动。但资产间相关系数并非随时间保持恒定。例如，在市场危机期间，各类资产之间的相关系数会上升，从而降低分散投资的益处。
4. 抵御通货膨胀：部分个股或行业能够提供抗通胀保护，但其能力因企业而异，取决于将成本转嫁给客户的能力。
5. 客户投资考量至关重要：需结合投资者目标、风险承受力、投资期限等确定股票投资比例。此外，近年来投资者对环境、社会和治理（ESG ）及可持续投资的兴趣日益增长。

## 股东参与

1. 股东参与：指投资者主动与公司进行互动的过程，其核心在于通过沟通、建议或投票等方式影响公司决策，推动公司治理优化与长期价值提升。这一过程不仅有助于形成更有效的公司治理文化，让投资者通过直接对话获取更多关于公司战略、风险等方面的信息，还能惠及员工、客户等其他利益相关方，尤其对关注ESG等非财务因素的股东而言，可借此推动公司落实可持续发展举措。不过，实践中可能存在“搭便车者”现象，即未参与互动的投资者也能从公司绩效提升中获益却无需承担参与成本，这一问题可能影响股东主动参与的积极性。

## 自由流通量调整

1. 自由流通量调整：某些证券特征使其作为指数成分股时不具备可投资性。许多股票指数会对流通股进行自由流通量调整，即仅计入公众可交易的股份，排除创始人、政府或其他公司持有的股份。当一家公司在市场上流通的股份仅占总发行股的一小部分时，交易可能产生不成比例的影响，例如流动性不足和交易成本高。这种调整旨在更真实地反映市场实际可交易的股票规模，提升指数对投资者的参考价值。

## 股票迁移问题

1. 随着股票市值增长，其所属类别可能从小盘股逐步升至中盘股乃至大盘股。为限制股票迁移带来的问题并降低交易成本，通常采用以下策略：缓冲区设置（Buffering）和分组处理（Packeting）。缓冲区设置（Buffering）：在不同指数分类的临界点（如市值划分阈值）周围设立缓冲区间，用于判断股票是否需要调整指数归属。机制：若股票市值处于缓冲区内，无论是否接近临界点，均维持其当前指数分类，暂不调整。✓作用：减少因市值小幅波动导致的频繁调仓，降低交易成本和市场冲击。✓分组处理（Packeting）：将单一股票的持仓拆分为多个部分，各部分适用不同的指数调整规则。机制：例如，某只股票部分持仓按小盘股指数规则处理，另一部分按中盘股规则处理，避免因整体市值✓跨越临界点而触发全部调仓。作用：通过分散持仓的归属逻辑，降低组合换手率和交易成本，尤其适用于跟踪多只指数的投资组合。✓
