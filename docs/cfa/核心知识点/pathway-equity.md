# 权益 · Equity（Pathway）

## 基于因子的策略

1. 基于因子的策略既保留了指数基金的低成本优势，又通过对各类因子的暴露提供预期回报，常见因子包括：价值（Value）、规模（Size）、动能（Momentum ）、波动性（Volatility）、质量（Quality）。
2. 基于指数的因子策略可替代传统的市值加权指数投资组合，或作为其补充，帮助投资者在承担特定风险的同时优化长期回报结构。
3. 基于因子的策略可以是收益导向型、风险导向型或分散投资导向型。
4. 相对于主动管理而言：对于那些认为“审慎筛选有望获得更高回报模式的股票组合”是明智之举的投资者，基于因子的策略可能更具优势；因子策略可提供对特定市场板块的“近乎纯粹”的风险敞口，且有众多基准可用于衡量其表现；。因子策略费用通常较低，因为因子策略基于既定规则运行，无需持续监控

## 交易所交易基金

1. 交易所交易基金（ETF ）是一种集合投资工具。它具有独特的结构：既需要基金管理人，也需要授权参与机构（Authorized Participant）——该机构可向管理人交付资产。授权参与机构的职责：做市商角色：作为ETF的流动性提供者，维持二级市场的买卖交易。申购赎回中介：在ETF份额的创设或赎回过程中，充当投资者与基金管理人之间的桥梁
2. 当授权参与机构需创设ETF份额时，需向基金管理人交付一篮子标的股票（如跟踪指数的成分股组合），作为交换，其将获得可向公众出售的ETF份额。这一机制确保ETF净值与标的资产价值紧密联动，并通过实物申赎降低现金摩擦成本。
3. ETF结构的优势：交易便捷、管理费低、税收效率高。
4. ETF结构的劣势：买卖价差成本、佣金费用、流动性风险。
5. 可供跟踪的基准指数数量远多于现有ETF产品，意味着部分细分市场或策略可能缺乏对应的ETF工具。

## 组合构建-完全复制

1. 完全复制是指基金经理持有指数所包含的所有证券，且权重与指数实际权重高度匹配的投资方法。
2. 优势精准匹配指数表现：通过完全复制指数成分及权重，通常能直接实现“跟踪指数回报”的核心目标，误差较小；逻辑简单透明：策略规则清晰，易于投资者理解和评估，无需依赖复杂的模型或主观判断。
3. 实施条件资金规模适配：管理的资产规模需足够大，以覆盖指数所有成分股的最小投资单位；市场流动性充足：指数成分股需具备充分的流动性，确保基金经理能以合理成本买卖证券，避免大额交易冲击市场价格；成分股可交易性：指数成分股需在市场中可正常交易，若存在部分成分股因政策限制、停牌等原因无法买卖，则无法实现完全复制。

## 组合构建-分层抽样

1. 投资组合经理虽倾向于通过完全复制指数获取收益，但实际中常因操作限制而采用分层抽样。部分股票指数成分股数量庞大，且并非所有成分股都具备高交易流动性，完全复制会导致交易成本高昂，尤其在扩大投资组合规模时，经纪佣金等费用也会因成分股数量多而激增，同时有限的资金规模难以覆盖所有成分股的最小投资单位。因此，分层抽样通过按维度划分层级并选取代表性样本，在跟踪误差与交易成本间实现平衡，成为更可行的指数跟踪策略。
2. 优势更贴近的指数跟踪：通过分层控制样本与指数在关键维度（如行业、市值、风险因子等）的一致性，减少跟踪误差。

## 组合构建-最优化

1. 诸如完全复制和分层抽样等指数投资组合构建的优化方法均以跟踪指数为目标。优化通常指在一个或多个约束条件下，最大化某一理想特征或最小化某一非理想特征，其核心目标是最小化指数跟踪误差。常见的约束条件是成分股的数量限制：如投资组合持有的成分股不超过
50. 只；市值门槛：仅限纳入市值高于特定水平的股票；风格特征匹配：要求投资组合的风格（如价值、成长等）与基准指数一致；交易单位限制：仅限以整数手（如100股）进行交易；再平衡成本控制：仅使用再平衡成本较低的股票。
2. 优势：跟踪误差更低。
3. 劣势：样本外有效性不足、操作成本较高。

## 主动风险

1. 主动风险的计算更为复杂。与主动份额一样，主动风险也用于衡量投资组合中证券权重与基准指数中证券权重的差异。
2. 主动份额与主动风险的关系：虽然较高的主动份额通常伴随较高的主动风险，但并非总是如此。主动风险受证券间交叉相关性的影响，而主动份额则不受此影响。
3. 投资组合经理的可控性：主动份额：可通过调整持仓证券的种类及权重完全控制。主动风险：无法完全控制，因其依赖于证券的相关性和波动性等不可控因素。
4. 主动份额仅衡量持仓结构与基准的静态差异（如是否持有基准外证券、权重偏离度），而主动风险需结合市场动态，通过资产间的风险联动性（协方差）评估动态跟踪误差。

## 构建良好的投资组合

1. 一个构建良好的投资组合应产生与投资者风险和回报预期相符的结果。它不能保证相对于合适基准的超额回报，尤其是在较短期限内，但它旨在呈现基金经理所期望并向投资者承诺的风险特征。
2. 构建良好的投资组合具备以下特点：拥有清晰的投资理念和连贯一致的投资流程；具备向投资者承诺的风险和结构特征；采用风险高效的实现方法；就其策略而言，运营成本合理较低。
3. 在一个构建良好的投资组合中，我们寻求与投资者预期和限制相一致的风险暴露，以及相对于总风险而言较低的特质风险（非系统性风险）。如果两种产品具有可比的因子暴露，在成本相近的情况下，绝对波动率和主动风险较低的产品可能更受青睐。如果两种产品的主动风险和绝对风险相似，投资组合成本相近，且基金经理的阿尔法能力相近，那么主动份额较高的产品更可取，因为它能更好地利用基金经理的阿尔法能力，预期回报也会更高。

## 只做多策略

1. 投资者采用只做多策略的一个主要动机是人们普遍认为承担市场风险能够在长期获得正的风险溢价。投资者可能还认为，从规模、价值或动量等其他风险来源也能获取风险溢价。
2. 只做多投资，尤其是专注于大盘股的策略，通常比其他投资方式具有更大的投资容量。
3. 普通股是有限责任金融工具。股价最低可跌至零，所以只做多的普通股投资者可能遭受的最大损失就是其投入股票的资金数额。因此，只做多投资为投资者的损失设定了一个明确的下限。

## 多空策略

1. 投资者可能因多种原因对多空策略感兴趣。例如，与只做多策略相比，允许卖空时能更有力地表达对负面观点的确信。此外，卖空有助于降低对行业、地区或整体市场走势的风险敞口，使基金经理能够专注于自身独特的技能。最后，要充分获取风险因子带来的益处需要采用多空策略（即卖空大盘股、做多小盘股；卖空成长股、做多价值股；卖空价格动量弱的股票、做多价格动量强的股票等）。只做多投资者只能从部分投资机会中获利。
2. 在多空策略中，头寸权重可以为负，且权重之和不一定限制为1。一些多空投资组合的总风险敞口甚至可能小于1。多头头寸绝对值减去空头头寸绝对值称为投资组合的净敞口。多头头寸加上空头头寸绝对值称为投资组合的总敞口。
