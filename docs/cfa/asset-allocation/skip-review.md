### Risk-parity 缺项为什么实质影响答案？

以下仅为检验充分条件的数学反例，不是给原题补造数据。将 returns 以百分数数值表示，设四资产 covariance matrix 为：

$$\Sigma=\begin{pmatrix}100&0&0&0\\0&25&6.25&6.25\\0&6.25&25&6.25\\0&6.25&6.25&25\end{pmatrix}$$

第一项债券与其他资产的 covariance 均为 0，确实最低；矩阵为 positive definite。令后三项各权重为 $y$、债券为 $x$，相等风险贡献要求 $100x^2=37.5y^2$。结合 $x+3y=1$，得到债券权重约 **16.95% < 25%**。将其 expected return 设得最低也不改变此结果。

若另加债券自身 volatility 较低等条件，结果可以反向。原题没有这些数值，故“最低共变 → 必须高于 25%”缺少充分条件，不能只因常见 bonds 形象而强定 C。
