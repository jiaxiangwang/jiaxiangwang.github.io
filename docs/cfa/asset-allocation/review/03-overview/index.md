# Overview of Asset Allocation

## What problem does this module solve?

同样的金融资产，因未来收入、义务和目标不同，会需要不同配置。本 Module 先确定目标与责任，再识别完整经济风险和失败标准，最后设计机会集、因子检查与再平衡。

::: info 学习主线
目标与授权 → 完整财富 → 风险定义 → 分类与因子 → 风险恢复
:::

## Exam Importance

- **Core：** 经济资产负债表、三种 risk definitions、资产类别与因子暴露、SAA/TAA/rebalancing 的分工。
- **Important formulas：** economic net worth；无需为本 Module 增加复杂 optimizer 推导。
- **Common Trap：** 忽略 future consumption / human capital；资产类不重叠≠因子不重叠；有 bands≠主动 TAA。
- **Constructed Response：** 用“目标→风险定义→方法”论证；解释既有暴露、治理权责和 corridor 的条件方向。
