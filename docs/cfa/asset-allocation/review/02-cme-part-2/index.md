# CME Part 2

## What problem does this module solve?

把宏观观点转化为各资产的回报与风险。本 Module 先建立决策框架，再练习识别题干条件，最后把判断接到其他 Modules 的配置决策。

## 学习目标与 2027 范围

以下是根据仓库 outline 和本地题目建立的复习能力目标，不冒充逐条官方 LOS：

- 将 Yield、Risk Premium 与实现回报分开。
- 从盈利、分红与估值拆解 Equity Return。
- 把租金、Cap Rate 与估值平滑串起来。
- 区分 PPP 长期锚与 Capital Flows 短期力量。
- 让 Variance–Covariance Matrix 反映真实风险。

## Exam Importance

- **Core：** bond horizon/duration、G–K、Singer–Terhaar、cap-rate 相对变化、PPP、VCV 参数。
- **Important formulas：** 各风险溢价、equity income/growth/repricing、property return、相对通胀、shrinkage。
- **Common Trap：** 收益率≠实现回报；required premium≠便宜；bp change≠relative cap-rate change；observed risk≠true risk。
- **Constructed Response：** 逐资产解释预期、检查长期可持续性、比较 emerging equity/debt 风险、识别估值平滑问题。
