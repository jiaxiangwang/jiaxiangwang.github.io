# CME Part 2 — Module Review

## Big Picture

把 Part 1 的经济环境转为可以进入配置的回报、波动和相关性，并检查不同资产模型的口径是否一致。

## Core Framework

宏观环境 → cash-flow growth + discount rate → 各类风险补偿 → price/reinvestment/valuation effects → currency conversion → VCV 与尾部场景。

## Must Remember

- Bond building blocks 不重复加已包含在 nominal risk-free rate 的 inflation。
- $H$ 与 Macaulay Duration 决定两种风险相对强弱；Modified Duration 用于价格敏感度。
- G–K 的净发行是减号；P/E 与 cap rate 都用相对变化。
- Singer–Terhaar 整合市场使用 global systematic risk，partial integration 看权重。
- PPP 看相对通胀且依赖报价；资金流会造成短期偏离。
- 平滑与少样本 VCV 会令配置低估共同风险。

## Exam Integration

**Source: Original CFA-style（仅整合复习）。**

1. A forecast assumes higher nominal growth, stable valuation multiples and unchanged shares outstanding. **Explain** how to build equity return and why a real estate forecast still needs a cap-rate assumption.

**Minimum Passing Answer:** Equity return is dividend yield plus nominal earnings growth when share count and P/E are stable. Property return also includes income and NOI growth, but cap-rate changes reprice the asset and can offset that growth.

2. A private-property index reports low volatility and low equity correlation. A three-year bond investment has five-year Macaulay duration. **Identify** one hidden risk in each forecast.

**Scoring Points：** appraisal smoothing understates property risk/correlation；bond price risk dominates reinvestment over the shorter horizon。两项均应在 MVO 输入前处理，而非等优化后再解释。
