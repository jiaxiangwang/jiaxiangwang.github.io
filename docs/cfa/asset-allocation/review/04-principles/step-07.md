# Step 7 — 把配置经验法当作基准而非答案

## 简单规则为什么仍有用？

输入误差大、治理能力有限时，简单规则透明、低成本、容易执行，能成为检查复杂 optimizer 的 benchmark。但它们省略了目标、负债、CME 或部分投资者差异，不能把可理解性等同于最优性。

| Heuristic / model | 核心特征 | 不能声称什么 |
| --- | --- | --- |
| 60/40 | 固定 equity/bond split | 不保证对当前目标/风险偏好最优 |
| 120 minus age | Equity allocation 随年龄下降 | 年龄不能包办 human capital、负债和风险容量 |
| 1/N | 每类等 capital weight，定期重平衡 | 不使用 returns/volatility/correlation，不是等 risk |
| Endowment / Yale model | 较多 alternatives、active management、illiquidity premium | 不适合所有养老金或需要近期支出的机构 |
| Norway model | 较多透明、可规模化 public-market exposure，重成本/治理并考虑 ESG | 不等于以复杂主动私募为核心的 endowment model |

## Endowment 模型先要满足 Liquidity Budget

长期稳定 inflows、可预测支出和足够治理资源，才支持承受锁定期、capital calls 和 manager dispersion。较高 expected illiquidity premium 是对不能立即撤资的补偿，不能当成保证收益或“有私募就更先进”。

SPP 的目标是达到全额资金并对冲负债，不能因为优秀 endowments 多配 alternatives 就照搬；模型适合另一类投资者不是此投资者的理由。Norway 与 Yale 的识别也要围绕 public-market scalability 和 active illiquid assets 的差别。

## Benchmark 的真正用途

将 MVO 结果与简单规则比较，可以发现集中权重是否只由噪声驱动；比较的评价指标应与投资目标一致。如果目标是 funding ratio stability，不能仅用 asset Sharpe 判复杂模型优于 60/40。

**Exam Trigger — Identify / Critique：** 1/N 不考虑投资特征、age rule 不处理完整经济资产负债表、endowment 模型要求 liquidity / governance 能力。**Boundary Condition：** 简单规则不是天然差，但采用前必须说明忽略了什么、是否适合目标。

## Immediate Practice

Source: Local Other AA，No.2025072102000029 — adapted；答案为推导。

Which statement is **most accurate**?

A. 1/N exploits differences in MCTR.\
B. The endowment model seeks illiquidity premiums.\
C. 120 minus age is a full risk-tolerance optimization.

**Answer: B.** A 混淆 equal capital 与 risk budgeting；C 给年龄规则赋予了不存在的完整优化能力。
