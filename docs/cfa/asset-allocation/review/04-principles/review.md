# Principles of Asset Allocation · Module Review

## Big Picture

工具选择由风险定义决定：asset efficiency 用 MVO / risk budget；支付义务用 liability-relative；多目标用 goals-based；路径与实施由 simulation 检查。

## Core Framework

目标与风险定义 → CME 输入 → 合适的优化/目标模型 → 稳健性与约束 → 资金/风险预算 → 多期检验 → 实施政策。

## Must Remember

- $U=\mu-0.5\lambda\sigma^2$（小数）；百分数数值写 $0.005$。
- Risk-free mixing 应比较同目标回报下的 volatility。
- Reverse optimization 推均衡预期；Black–Litterman 加 views；resampling 不能消除错误输入。
- $MCTR_i=\beta_{i,p}\sigma_p$；$ACTR_i=w_iMCTR_i$；最优等比条件看 constraints。
- $A-L$ 与 $A/L$ 不可互代；负债越复杂、多期贡献目标越明确，越需要 integrated ALM。
- Goals funding 使用 horizon/probability-adjusted minimum return；现金流时点决定 PV。

## Exam Integration

**Source: Local 原版书 AA，No.2018031301000005 — adapted；答案为推导。**

A pension fund has assets $10bn and liabilities $8.5bn whose returns are driven by index-linked government bonds. **Recommend** a two-portfolio structure.

**Minimum Passing Answer:** Allocate 85% to a liability-matching index-linked government-bond portfolio and 15% to return-seeking assets, assuming the bonds adequately replicate liability risks.

**Source: Original CFA-style（仅整合复习）。**

A client's 10-year goal requires 90% success. Portfolio A has a higher mean but a lower 90%-success minimum return than B. **Select** the lower-funding-cost portfolio and **identify** one next check.

**Answer:** B；use its matched minimum return to discount the goal。再检查目标现金流路径、liquidity 与联合资金充足性，而不是仅比较 mean/Sharpe。
