# Principles of Asset Allocation

## What problem does this module solve?

一组 CME 可以服务不同目标，模型选择应服从目标。本 Module 从资产效率与效用出发，处理输入和路径风险，再用风险预算、负债方法与目标 funding 形成配置。

::: info 学习主线
效率与适合性 → 稳健输入 → 路径 → 风险分配 → 支付 / 目标 → 基准检查
:::

## Exam Importance

- **Core：** utility、同目标风险组合、MVO 改进、MCTR/ACTR、三种 liability methods、goals funding。
- **Important formulas：** utility 的输入口径；risk-free mix；MCTR/ACTR；funding ratio；目标现值与增长支出。
- **Common Trap：** 最高均值≠最高效用/成功率；reverse optimization 不反推风险；risk parity 不等本金；surplus 不变≠ratio 不变。
- **Constructed Response：** Contrast model inputs/outputs；按 horizon/probability 选组合并 justify；给足额 hedge 与 surplus 一个明确分工。
