# Real-World Constraints

## What problem does this module solve?

理论权重只有能买入、能支付、能监督，才有投资价值。本 Module 用规模、现金流、期限、税和授权检验可执行性，再为战术观点与行为偏差建立规则。

::: info 学习主线
机会集边界 → 现金可用性 → 战略前提变化 → 税后财富 → 授权 TAA → 执行纪律
:::

## Exam Importance

- **Core：** 绝对金额与 capacity、liquidity map、SAA review triggers、after-tax 输入、TAA 边界与行为证据。
- **Important formulas：** AUM × weight；简化 after-tax mean/volatility；TAA 相对 SAA 的增量回报。
- **Common Trap：** 长期≠随时有 cash；最低投资额达标≠PE 合适；高 alpha≠可越 IPS；税后 correlation 不变需线性条件。
- **Constructed Response：** 每项不合适原因都由 case fact 支持；bias 需证据；early-retirement 分类需说明 horizon/inflows 变化。
