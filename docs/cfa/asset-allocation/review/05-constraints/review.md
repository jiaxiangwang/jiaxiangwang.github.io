# Real-World Constraints · Module Review

## Big Picture

投资目标和数学模型必须落进现实可行集合。可实施性来自规模、资金、税与政策，纪律来自治理和行为约束。

## Core Framework

目标资金/风险 → 产品与容量 → cash-flow / liquidity budget → tax / regulation → 执行与 rebalancing → 授权 TAA → bias-aware monitoring → SAA review。

## Must Remember

- 小账户 minimum ticket 与大账户 fund/strategy capacity 是不同约束。
- 必需支出、capital calls 与下降 inflows 先于争取 illiquidity premium。
- 线性 tax scaling 同时改 mean 和 volatility；correlation 不变有条件。
- Goals、constraints、beliefs 的 review trigger 要从具体事实判断。
- TAA 要在 IPS 内，净增量相对 SAA；长期改变应复核 SAA。
- Bias 识别必须给行为证据；资产分账户后仍看总体风险。

## Exam Integration

**Source: Local Other AA，Titan/Fordhart Case No.2025072102000052 — adapted；答案为推导。**

**Discuss** why the same 10% PE proposal can be problematic for a $10m endowment with falling inflows and a $2bn endowment investing in a $500m fund.

**Minimum Passing Answer:** The small endowment faces rising liquidity needs and concentration from the $1m minimum-sized commitment. The large endowment's $200m ticket is 40% of the PE vehicle, creating capacity and concentration issues. The two constraints arise for different reasons.

**Source: Original CFA-style（仅整合复习）。**

An investor refuses to sell equities after recent strong performance; a manager wants to override the IPS limit because a tactical forecast is favorable. **Identify** the two decision errors.

**Answer:** representativeness / unwarranted extrapolation；TAA outside authorization。处理方式是恢复书面再平衡纪律，并在执行前取得合法政策变更，而不是用预期 alpha 抹去约束。
