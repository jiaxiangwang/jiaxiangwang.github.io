# Asset Allocation

把 Asset Allocation 看成一套投资决策：**先认识投资者的经济风险，形成一致的市场预期；选择与目标相符的风险定义与配置工具；最后以流动性、税、政策和治理把权重落实。**

仓库 2027 outline 确定本 Topic 的以下五个 Learning Modules。每个 Module 均有 Overview、Review Steps 和 Module Review；默认中文理解与 CFA English recognition 配合。

## Learning Map

<ol class="course-map">
<li><a href="/cfa/asset-allocation/review/01-cme-part-1/">CME Part 1</a><span class="priority">6 Steps</span><p>宏观观点需要变成期限一致、逻辑一致、可检验的市场预期。本 Module 先恢复预测流程，再用增长、周期、通胀和政策解释资产面对的环境，最后检查开放经济约束。</p></li>
<li><a href="/cfa/asset-allocation/review/02-cme-part-2/">CME Part 2</a><span class="priority">5 Steps</span><p>经济预测不是资产回报。本 Module 将增长、通胀和政策分别接到债券、股票、房地产与汇率，再检查共同风险怎样进入配置输入。</p></li>
<li><a href="/cfa/asset-allocation/review/03-overview/">Overview of Asset Allocation</a><span class="priority">6 Steps</span><p>同样的金融资产，因未来收入、义务和目标不同，会需要不同配置。本 Module 先确定目标与责任，再识别完整经济风险和失败标准，最后设计机会集、因子检查与再平衡。</p></li>
<li><a href="/cfa/asset-allocation/review/04-principles/">Principles of Asset Allocation</a><span class="priority">7 Steps</span><p>一组 CME 可以服务不同目标，模型选择应服从目标。本 Module 从资产效率与效用出发，处理输入和路径风险，再用风险预算、负债方法与目标 funding 形成配置。</p></li>
<li><a href="/cfa/asset-allocation/review/05-constraints/">Real-World Constraints</a><span class="priority">6 Steps</span><p>理论权重只有能买入、能支付、能监督，才有投资价值。本 Module 用规模、现金流、期限、税和授权检验可执行性，再为战术观点与行为偏差建立规则。</p></li>
</ol>

## Cross-Module Decision Chain

Economic balance sheet / goals → CME（macro → asset returns / VCV）→ risk definition → MVO / liability-relative / goals-based → robustness / paths → liquidity / taxes / policy → rebalancing / TAA → feedback。

课程顺序先铺市场预期，再恢复投资者框架；真正执行时必须先确定投资者目标。两个顺序服务不同任务，最终应在 Topic Review 中合成同一决策链。
