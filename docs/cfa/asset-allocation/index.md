# CORE → Asset Allocation

把 Asset Allocation 看成一套投资决策：**先认识投资者的经济风险，形成一致的市场预期；选择与目标相符的风险定义与配置工具；最后以流动性、税、政策和治理把权重落实。**

仓库 2027 outline 确定本 Topic 的以下五个 Learning Modules。每个 Module 均有 Overview、Review Steps 和 Module Review；默认中文理解与 CFA English recognition 配合。

## Cross-Module Decision Chain

Economic balance sheet / goals → CME（macro → asset returns / VCV）→ risk definition → MVO / liability-relative / goals-based → robustness / paths → liquidity / taxes / policy → rebalancing / TAA → feedback。

课程顺序先铺市场预期，再恢复投资者框架；真正执行时必须先确定投资者目标。两个顺序服务不同任务，最终应在 Topic Review 中合成同一决策链。
