<template #analysis>

### Correct Answer

C. data-mining bias

### Why?

重复搜索找出足球与股市的显著关系，缺乏经济机制，属于 data mining。

### Distractor Analysis

A 需要以某初始数值为锚；B 需要抗拒改变现状；这里的直接证据是大量筛选变量。

### Knowledge Review

**Core：** 预测流程先明确资产与期限，最后检验并反馈；显著性要有经济机制支持。

CME 的估计误差会在 MVO 中被放大；使用稳健配置方法之前，先处理输入本身的质量。

**Boundary：** 长样本并不自动更可靠；制度改变会使历史平均失去代表性。

### Related Concepts

- [让 Variance–Covariance Matrix 反映真实风险](/cfa/asset-allocation/review/02-cme-part-2/step-05)

- 若指标只是同期相关，能否用于 TAA？

### Exam Takeaway

先检查数据与机制，再把统计结果当作配置输入。
