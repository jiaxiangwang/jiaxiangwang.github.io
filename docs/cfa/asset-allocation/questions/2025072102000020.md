Under which of the following scenarios is a Monte Carlo simulation **most likely** required when estimating an investor's future wealth?

</template>

<template #a>

There are no cash flows into or out of the portfolio over time

</template>

<template #b>

There are cash flows and terminal wealth is path dependent

</template>

<template #c>

There are cash flows but the terminal wealth is not path dependent

</template>

<template #analysis>

### Correct Answer

B. There are cash flows and terminal wealth is path dependent

### Why?

提款/注资使 terminal wealth 依赖 return sequence，需要多期路径模型。

### Distractor Analysis

A/C 都缺少题目所强调的 path-dependence 原因；并非无现金流永远不可模拟。

### Knowledge Review

**Core：** 有现金流时回报顺序影响 wealth；simulation 检验路径风险，scenario 解释特定冲击机制。

MVO 选单期效率，goals-based 定成功概率，Monte Carlo 检查多期实现；liquidity 与 rebalancing 规则必须在路径里体现。

**Boundary：** 模拟概率取决于指定模型；次数再多也不能弥补缺失的 tail、税与现金流假设。
