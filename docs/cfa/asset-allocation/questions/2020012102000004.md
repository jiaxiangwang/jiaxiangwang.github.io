# Case 2020012102000004

[Question Bank](/cfa/asset-allocation/questions/) · [Source & LOS 核验说明](/cfa/asset-allocation/sources)

## Vignette & Exhibits

An Australian investor is assessing historical and expected annual equity returns. Assume no change in shares outstanding.

| Input | Historical | Current / expected |
| --- | --- | --- |
| Government 10-year yield | 2.8% average | 2.3% current |
| Equity annual return | 4.6% average | −9.4% last year |
| Inflation | 2.3% average | 2.1% current; 2.3% expected |
| P/E | 15 at historical start | 14.5 current; 14.0 expected |
| Dividend income return | 2.6% average | 2.4% expected |
| Real earnings growth | 6.0% average | 5.0% expected |

### Scoring Points

以下为依据解题逻辑推导的可得分点，不是官方评分表。

- 使用一致历史期 annual equity return 4.6%。
- 扣历史 government yield 2.8%：4.6−2.8=1.8%。

### Minimum Passing Answer

Historical equity-vs-bonds premium = 4.6% − 2.8% = 1.8%.

### Knowledge Review

**Core：** G–K 拆分收入、增长、股本与估值；Singer–Terhaar 根据市场整合程度区分系统风险与总风险补偿。

长期盈利输入接自 trend growth；全球整合和治理风险又影响 robust MVO 的预期与相关性假设。

**Boundary：** 整合过渡的估值增益不等于之后的均衡回报；required premium 本身不能证明资产便宜。

### Scoring Points

以下为依据解题逻辑推导的可得分点，不是官方评分表。
