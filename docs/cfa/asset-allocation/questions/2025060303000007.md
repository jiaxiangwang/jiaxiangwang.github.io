<template #prompt>

An analyst uses this growth-gap Taylor rule: $i^*=r^*+\pi_e+0.5(\pi_e-\pi^*)+0.5(g_e-g_{trend})$.

| Input | Value |
| --- | --- |
| Expected inflation | 4% |
| Target inflation | 3% |
| Expected real growth | 5% |
| Trend real growth | 3% |
| Neutral real policy rate | 2% |

The target nominal policy rate is:

</template>

<template #a>

3.5%.

</template>

<template #b>

4.5%.

</template>

<template #c>

7.5%.

</template>

<template #analysis>

### Correct Answer

C. 7.5%.

### Why?

先以 neutral real rate + expected inflation 构成基准：2+4=6%；再加 0.5(4−3)+0.5(5−3)=1.5%，合计 7.5%。

### Distractor Analysis

A/B 漏掉或误处理 nominal baseline 与 gap adjustments。题目采用 growth-gap 版本，不把它替代所有 output-gap 定义。

### Knowledge Review

**Core：** 政策组合通过短端、债券供给与增长/通胀预期影响曲线；Taylor rule 拆解基准与反应项。

政策先进入 business cycle 判断，再通过 duration 与 risk premiums 进入固定收益预期，不能直接等同于实现回报。

**Boundary：** 按题干定义使用 gap；宽松货币政策与财政扩张通常使曲线变陡，但不保证长债收益率必涨。
