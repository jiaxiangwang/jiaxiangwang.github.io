<template #prompt>

Which of the following factors would **most likely** lead to a  wider optimal corridor width for an asset class?

</template>

<template #a>

Higher volatility within the asset class

</template>

<template #b>

Higher volatility within the rest of the portfolio

</template>

<template #c>

Higher correlation of the asset class with the rest of the portfolio

</template>

<template #analysis>

### Correct Answer

C. Higher correlation of the asset class with the rest of the portfolio

### Why?

资产与其他组合相关更高时一起运动，偏离引起的相对风险结构变化较小，典型 optimal band 更宽。

### Distractor Analysis

A/B volatility 增加风险偏离代价，在该 cost-risk 权衡中通常支持 narrower bands。

### Knowledge Review

**Core：** 再平衡控制 drift；宽度平衡偏离风险与交易/税成本，高相关通常支持更宽范围。

Rebalancing 把 SAA 风险目标变成操作政策，taxes 与 liquidity 改变其成本；它与基于短期观点的 TAA 有不同目的。

**Boundary：** 说明 volatility 与 corridor 的口径；非流动投资无法套用可随时卖回目标的规则。

### Exam Takeaway

交易成本提高使范围更宽，风险偏离更昂贵则更窄。
