The investment committee of an institutional investor typically retains approval of:

</template>

portfolio rebalancing.

</template>

<template #b>

security selection decisions.

</template>

<template #c>

strategic asset allocation decisions.

<template #analysis>

### Correct Answer

C. strategic asset allocation decisions.

### Why?

委员会批准 SAA，常规 rebalancing 和 security selection 按授权实施。

### Distractor Analysis

A/B 是典型执行决策；除非题干另给特别保留权。

### Knowledge Review

**Core：** IPS 定义目标与授权，SAA 决定长期政策风险，TAA 与 rebalancing 在不同触发下实施。

治理先于经济资产负债表与优化；后续 Real-World Constraints 中的 TAA、税务与行为政策都须落在授权范围内。

**Boundary：** 委员会透明授权是一项治理优点，不证明其成员专业能力与监督机制也充分。
