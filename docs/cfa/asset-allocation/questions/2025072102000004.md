Which of the following asset allocation approaches uses the volatility of the portfolio's return as its **primary** measure of risk?

Asset-only approach

</template>

<template #analysis>

### Correct Answer

A. Asset-only approach

### Why?

Asset-only 常将 portfolio return volatility 作为主要风险指标。

### Distractor Analysis

B 看 goal shortfall；C 看 surplus/funding-relative risk。

### Knowledge Review

**Core：** Asset-only 看资产风险效率，liability-relative 看相对支付义务，goals-based 看目标 shortfall。

同一组 CME 可进入不同配置目标函数；Principles 中的方法选择必须继承这里的风险定义，而不能倒过来让工具决定目标。

**Boundary：** 机构也可以采用目标分层；低资产波动并不保证低 funding risk。
