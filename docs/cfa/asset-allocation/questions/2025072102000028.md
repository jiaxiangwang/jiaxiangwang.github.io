The absolute contribution to total risk for an asset class can be calculated as the product of the asset class weight in the portfolio and:

</template>

<template #a>

the asset class beta.

</template>

<template #b>

the portfolio return volatility.

</template>

<template #c>

its marginal contribution to total risk.

</template>

<template #analysis>

### Correct Answer

C. its marginal contribution to total risk.

### Why?

ACTR=w_i×MCTR_i。

### Distractor Analysis

A 少了 portfolio volatility；B 少了相对组合 beta/共变结构。

### Knowledge Review

**Core：** MCTR 是边际风险，ACTR 是权重乘边际风险；risk parity 平分贡献而非本金。

Factor/VCV 决定 MCTR；MVO 的最优条件解释为何 marginal risk 的回报应一致，但现实约束与 liabilities 会改变预算。

**Boundary：** 相等比例条件限于适用的 interior optimum；risk parity 也不能仅凭低收益率推资本权重。
