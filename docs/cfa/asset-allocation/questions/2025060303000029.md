<template #prompt>

An analyst wants to forecast a variance–covariance matrix of 200 assets with 4 common factors using the sample statistic method. How many distinct covariance elements need to be estimated?

</template>

<template #a>

800

</template>

<template #b>

19,900

</template>

<template #c>

40,000

</template>

<template #analysis>

### Correct Answer

B. 19,900

### Why?

sample-statistics 法对 200 assets 估两两独立 covariances：200×199/2=19,900。

### Distractor Analysis

A 的 800 是 200×4 factor exposures；C 的 40,000 重复计了对称矩阵格子且包含 diagonals。

### Knowledge Review

**Core：** VCV 捕捉共同风险；sample、factor 和 shrinkage 的取舍是噪声与结构的取舍。

风险估计接到 MVO、MCTR 和 simulation；appraisal smoothing 在输入端就会把非流动资产看起来过度有吸引力。

**Boundary：** 静态 VCV 不能包办 regime change、tail risk 与 liquidity；factor model 要保留适当 residual risk。
