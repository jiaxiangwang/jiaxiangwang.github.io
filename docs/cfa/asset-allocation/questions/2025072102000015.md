An investment manager needs to select a liability-relative asset allocation approach for a conservative pension fund. The funding ratio of the pension fund is less than one and is not expected to increase. If the investment manager is looking to implement a single period asset allocation model, which of the following models is **most appropriate**?

</template>

<template #a>

The surplus optimization approach

</template>

<template #b>

The integrated asset-liability portfolios approach

</template>

<template #c>

The basic hedging/return-seeking portfolios approach

</template>

<template #analysis>

### Correct Answer

A. The surplus optimization approach

### Why?

题目明确单期、欠资且保守，surplus optimization 将 liabilities 纳入相对风险而不要求足额 hedge。

### Distractor Analysis

B 为多期 integrated model；C 的完整 hedge + surplus return-seeking 结构在持续欠资下不易足额建立。

### Knowledge Review

**Core：** 资产相对支付义务的风险决定方法；surplus 与 funding ratio 反映不同信息。

经济资产负债表同时识别 sponsor 经营风险；CME 的 rates/inflation 进入负债价值，governance 决定目标优先级和贡献政策。

**Boundary：** 负债估值与 cash-flow 风险不能用 asset Sharpe 替代；等额资产负债变化不保持 ratio，closed 不等于 frozen。
