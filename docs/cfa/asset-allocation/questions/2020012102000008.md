Current industrial-property cap rate is 5.7%; expected year-end cap rate 5.5%; real NOI growth 1%; inflation 1.5%. Estimate the next-year expected return using the cap-rate-change approximation.

</template>

<template #analysis>

### Conclusion

近似下一年 expected property return = 11.71%。

### Scoring Points

以下为依据解题逻辑推导的可得分点，不是官方评分表。

- NOI nominal growth≈1.0+1.5=2.5%。
- Cap-rate relative change=5.5/5.7−1=−3.5088%。
- Return≈5.7+2.5−(−3.5088)=11.7088%；以收入收益近似 cap_0。

### Minimum Passing Answer

Expected return ≈ 5.7% + 2.5% − (5.5/5.7 − 1) = 11.71%. A lower cap rate raises property value. This is the cap-rate-change approximation.

### Knowledge Review

**Core：** 收入收益与 NOI 增长支持回报，cap rate 的相对变化产生重估；appraisal smoothing 压低观察风险。

房地产预期不能脱离 inflation 与 rates；进入 MVO 和 liquidity 规划时必须修正估值平滑与实际 vehicle 风险。

**Boundary：** REIT 的短期 equity correlation 与长期 property correlation 不同；不能把长期 cap-rate 下降当持续增长来源。
