<template #prompt>

A mean–variance optimization uses only risky assets and does not allow negative weights. Which of the following statements about the resulting efficient frontier is **most accurate**?

</template>

<template #a>

The slope of the efficient frontier is flattest at the point representing the global minimum variance portfolio

</template>

<template #b>

The "kinks" in the slope of the efficient frontier represent the impact of leverage being applied and removed

</template>

<template #c>

The slope of the efficient frontier represents the rate at which the expected return increases per increase in risk

</template>

<template #analysis>

### Correct Answer

C. The slope of the efficient frontier represents the rate at which the expected return increases per increase in risk

### Why?

Frontier slope 是 expected return 对增加风险的边际变化率。

### Distractor Analysis

A GMV 附近上支通常较陡而非最平；B kinks 可以由 long-only constraints binding 造成，无需 leverage。

### Knowledge Review

**Core：** MVO 建有效边界，risk aversion 选 utility；加入无风险资产后比较同目标下的混合风险。

输入来自 CME，但 expected return 的小误差会被权重优化放大；下一步的 robust methods 与 simulation 分别处理输入和路径问题。

**Boundary：** 百分数与小数的 utility 系数不同；经典 tangency 结论依赖借贷与约束假设。
