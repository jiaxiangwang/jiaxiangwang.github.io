A foundation's investment policy statement specifies a mandate to minimize return standard deviation while targeting an expected return objective of 7%. Using a 3% risk-free rate, a mean-variance optimization produces the **highest** Sharpe ratio portfolio with an expected return of 8% and standard deviation of 11%. The percentage of this portfolio that should be combined with the risk-free asset to achieve the expected return objective of 7% with the **lowest** risk is **closest to**:

</template>

<template #a>

20%.

</template>

<template #b>

50%.

</template>

<template #c>

80%.

</template>

<template #analysis>

### Correct Answer

C. 80%.

### Why?

为 7% target：w=(7−3)/(8−3)=80%；cash=20%，mix volatility=0.8×11=8.8%。

### Distractor Analysis

A 是 cash weight；B 给的 target 仅 5.5%。

### Knowledge Review

**Core：** MVO 建有效边界，risk aversion 选 utility；加入无风险资产后比较同目标下的混合风险。

输入来自 CME，但 expected return 的小误差会被权重优化放大；下一步的 robust methods 与 simulation 分别处理输入和路径问题。

**Boundary：** 百分数与小数的 utility 系数不同；经典 tangency 结论依赖借贷与约束假设。
