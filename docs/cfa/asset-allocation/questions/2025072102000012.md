Which of the following statements about liability-relative asset allocation is **most accurate**?

</template>

<template #a>

Liquidity is one of the **primary** macro factors used to estimate the liability cash flows

</template>

A fully hedged portfolio can be constructed for a frozen pension plan with fixed liabilities

</template>

<template #c>

A factor-based approach cannot be implemented using the surplus optimization allocation method

<template #analysis>

### Correct Answer

B. A fully hedged portfolio can be constructed for a frozen pension plan with fixed liabilities

### Why?

Frozen、固定且可匹配 liabilities 可用 cash-flow/risk matching 建充分 hedge，假设工具可得。

### Distractor Analysis

A liquidity 不是典型估计 liability cash flows 的主要宏观驱动；C 无理由排除 factor-based surplus analysis。

### Knowledge Review

**Core：** 资产相对支付义务的风险决定方法；surplus 与 funding ratio 反映不同信息。

经济资产负债表同时识别 sponsor 经营风险；CME 的 rates/inflation 进入负债价值，governance 决定目标优先级和贡献政策。

**Boundary：** 负债估值与 cash-flow 风险不能用 asset Sharpe 替代；等额资产负债变化不保持 ratio，closed 不等于 frozen。
