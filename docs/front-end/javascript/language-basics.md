## 语法

ECMAScript的语法大量借鉴了C和其它类C语言的语法，如Java和Perel. 熟悉此类语言的开发人员可以轻松的掌握 ECMAScript 较为宽松的语法。

### 大小写敏感

需要理解的第一个概念是，ECMAScript所有内容都区分大小写，变量名，函数名和运算符均区分大小写。这意味着“test”和“Test”是不同的变量名。同样,"typeof" 不能作为函数名，因为它是关键字，虽然"typeof"是一个完全有效的函数名。

### 标识符

标识符是变量名、函数、属性或函数的参数名。
